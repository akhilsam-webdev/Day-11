# 🚀 Day-11 Practice – Advanced Backend Development

This project is part of my **backend development journey**, where I implemented more advanced concepts using **Node.js, Express.js, and MongoDB**, focusing on building structured and scalable APIs.

---

## ⚙️ Tech Stack

* **Node.js**
* **Express.js**
* **MongoDB + Mongoose**
* **JavaScript (ES6)**
* **REST API**

---

## 📦 Packages Used

* **express** → Backend framework for building APIs
* **mongoose** → MongoDB object modeling
* **dotenv** → Manage environment variables
* **cors** *(if used)* → Handle cross-origin requests
* **nodemon** *(dev)* → Auto-restart server during development

---

## 📚 What I Learned

* Designing RESTful APIs
* Connecting backend with MongoDB
* Creating schemas using Mongoose
* Performing CRUD operations (Create, Read, Update, Delete)
* Structuring backend projects (routes, models, config)
* Handling async operations with async/await
* Improving code organization
